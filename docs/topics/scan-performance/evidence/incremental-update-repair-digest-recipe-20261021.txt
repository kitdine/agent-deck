## 原始目录算法

两目录使用完全相同的筛选集合。以下是原生成调用的有效代码，`repo` 为已验证的工作树根目录：

```python
from pathlib import Path
import hashlib

repo = Path.cwd()
suffixes = {'.go', '.json', '.sql', '.swift', '.plist', '.xcstrings'}

def digest(p, suffixes):
    if p.is_file():
        return hashlib.sha256(p.read_bytes()).hexdigest()
    entries = [
        str(x.relative_to(repo)) + '\0' + hashlib.sha256(x.read_bytes()).hexdigest()
        for x in sorted(p.rglob('*'))
        if x.is_file() and (x.suffix in suffixes or x.name == 'README.md')
    ]
    return hashlib.sha256('\n'.join(entries).encode()).hexdigest()
```

1. **枚举与筛选。** 递归 `Path.rglob('*')`，先排序再筛选。仅纳入 `is_file()` 且后缀为上述六种之一，
   或文件名恰好为 `README.md` 的项。大小写敏感，不按目录选择不同后缀。
   不使用 Git tracked、ignore、隐藏文件、测试文件、生成文件或 untracked 筛选；满足规则的 JSON fixture
   和 `_test.go` 也在清单中。Python 3.15 的默认 `recurse_symlinks=False` 不递归 symlink 目录；
   原代码没有额外排除 symlink 文件，`is_file()` 与 `read_bytes()` 会跟随文件 symlink。
2. **排序。** 对 `Path` 对象执行 `sorted`，采用 POSIX pathlib 路径分量字符串的字典序、大小写敏感的
   Unicode 码点比较，不受 locale 影响；不改为按 basename、摘要或遍历返回顺序排序。
3. **逐文件摘要。** SHA-256 的输入为 `read_bytes()` 原始文件字节；不解码内容，不处理 BOM、CRLF、
   空白或末尾换行。摘要为小写 64 位十六进制字符串。
4. **路径。** 使用 `str(x.relative_to(repo))`，即仓库根相对路径，保留 `cmd/agentdeck/` 或
   `apps/macos/AgentDeckApp/` 前缀，以 `/` 分隔，无 `./`，不纳入绝对工作树路径，不做 Unicode 归一化。
5. **单项拼接。** `path + U+0000 + lowercase_sha256`；中间是一个 NUL 字节 `00`，没有空格、冒号或
   JSON 引号。文件大小及清单元数据不参与摘要。
6. **目录拼接。** 项之间仅放一个 LF 字节 `0a`，最后一项后没有 LF。然后调用无参数 `encode()`：
   UTF-8、strict、无 BOM。对所得字节再做 SHA-256。空清单对应空字节串摘要。
