# Work Signals — Review Records

This topic's document phase produces **one record for the whole document set**,
`documents.md`, written when the first round runs.

The five documents constrain each other, so they are reviewed together and carry
a single verdict. Reviewing them one at a time is what produced fourteen rounds
in the discarded first pass, six of which repaired damage the process itself had
caused. The reasoning is in [`../tasks.md`](../tasks.md).

Task reviews that follow the document phase keep the project's normal shape: one
record per task.
