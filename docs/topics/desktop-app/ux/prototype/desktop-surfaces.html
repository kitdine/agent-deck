Widget

A sandboxed extension reading only the redacted App Group projection. Everything shown is an aggregate, because that is all the projection is permitted to carry.

What this board settles, and what it cannot. It settles hierarchy, density, copy, state coverage, proportion at both width bounds, and both appearances. It does not settle real SF type metrics, Dynamic Type reflow, VoiceOver order, or contrast measured on device — those are presentation-adjacent claims that only the running app can support, and they stay in the manual acceptance checklist. A specimen is presentation evidence; it never substitutes for runtime evidence.
